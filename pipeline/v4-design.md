# 星图 V4 设计决策

日期：2026-09-23  
适用端：`portal-desktop` Electron + React + Vite  
唯一需求基准：`pipeline/v4-requirements.md`

## 1. 本轮取舍

V4 保留 V3 的 `@xyflow/react` 数据与交互底座，只收敛信息密度、全屏语义和连线可发现性。不新增 contract、baseline、hash 或形式化 gate；本地数据仍沿用 schema 3，通过 `beings:star-map:v4` 读取并兼容迁移 V3 缓存。

## 2. 画布专注模式，而非 OS 全屏

- 「专注画布」只设置页面内状态，用 fixed overlay 覆盖应用视口；左侧星轨、右侧详情、星图顶栏以及应用外层导航均被画布覆盖，不调用 `win.setFullScreen`。
- 画布右上角始终保留「退出专注」，`Esc` 也可退出，避免进入后失去返回路径。
- 删除外置浏览器按钮。当前应用页面仍挂载 `beings://chat/...` iframe，单改 URL 无法保证普通浏览器完成加载；本轮范围又不允许改聊天主流程，因此不保留已知半残入口。

## 3. 节点遮挡：选 B，自适应细节分级

对比：

| 方案 | 优点 | 代价 | 决策 |
| --- | --- | --- | --- |
| A 折叠后向下展开 | 单节点可承载长文本，心智模型直接 | 展开仍会推高卡片并覆盖下方节点；多个卡片展开后画布布局不稳定 | 不采用 |
| B 缩放分级、尺寸恒定 | 缩放时布局不跳动；批量浏览与连线位置稳定 | 高倍缩放仍需克制信息量，完整详情要留在右栏 | 采用 |

节点固定为 `214 × 86`：普通档显示状态、标题、负责人；高倍档在同一行内把负责人和说明组合为截断摘要，不新增卡片行高；低倍档仍只显示站级摘要。完整字段继续由右侧详情承载。跨站边仅在低倍档聚合到站，展开后恢复为真实节点到节点的边，避免新连线被站级聚合吞掉。

## 4. 连线模式

只读参考 `E:\Agentspace\co-design-client` 的 `DependencyArrows.tsx` 后，提炼四个可迁移模式：

1. 连接点的视觉尺寸与缩放解耦，参考实现使用 16px 端口，不再采用 V3 的 8px 点。
2. 点击命中大于视觉尺寸、目标吸附再大一档；参考实现是 22px 命中半径和 64px 吸附半径。React Flow 中采用 16px 手柄与 48px `connectionRadius`，兼顾易命中和误连风险。
3. 输入/输出要有不同符号和动作语义：左侧 `●` 表示连入，右侧 `＋` 表示从这里拖出；hover 显示短标签，节点 hover、连线中和合法目标均强化为紫色。
4. 拖动必须有连续反馈：虚线贝塞尔线跟随鼠标，提示条切换为「正在从 X 连线」，松手成功后显示 `A → B`。

连接仍写入当前星轨的 `customTransitions`，任意两个不同节点都可以自由组合；默认边和自定义边继续支持选中后 Delete 删除。

## 5. 导航与信息密度

- 移除 MiniMap；右下角缩放 Controls 保留。
- 左侧删除底部默认流程描述，只保留新建区和星轨列表；按钮文案改为「新建」。
- 星图内部顶栏压成 48px 单行；星图可见时隐藏弹窗重复标题行，保留一行功能切换，因此总计两行。常用动作留「专注画布」和「关闭」；流程版本、状态图例和低频「重置本地编辑」放入「更多」。原第二行 meta bar 删除。

## 6. 范围边界

修改仅位于 `desktop/renderer/pipeline/`。不改 Electron 主进程、preload、聊天 iframe、主导航和其他产品页面；也不修改只读参考仓。V4 仍是本地可编辑原型，Town/BL 持久化、多人协同和纯浏览器独立路由不在本轮范围。
